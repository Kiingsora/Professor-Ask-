Paramètres

Configure le fournisseur IA, la connexion au compte, le contexte vidéo et le comportement des réponses.

Enregistré

Fournisseur IA

Choisis le moteur qui répondra dans le panneau YouTube.

Connexion Codex avec ChatGPT

Le bouton lance le flux OAuth officiel de Codex. Le navigateur s’ouvre sur ChatGPT, puis Codex conserve et renouvelle lui-même la session. Professor Ask ne reçoit pas le token OAuth.

Connexion Gemini

Pour une application tierce, Professor Ask utilise soit Google Cloud OAuth avec Vertex AI, soit la Gemini API. L’OAuth interne du Gemini CLI grand public n’est pas réutilisé.

Cette connexion ouvre l’authentification Google via gcloud auth application-default login. Google Cloud CLI doit être installé sur la machine.

Réponses de l’IA

Détermine comment Professor Ask formule et vérifie ses réponses.

Contexte vidéo

Contrôle la quantité de transcription envoyée avec chaque question.
