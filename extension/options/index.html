Compte ChatGPT / Codex

Compte Google Antigravity

Professor Ask utilise maintenant un client OAuth public propre à l’extension, avec PKCE. Aucun client_secret, CLI, serveur localhost ou programme compagnon n’est nécessaire.

Le gateway Antigravity reste une API Google non documentée comme contrat tiers stable. L’authentification, elle, passe par l’API Identity du navigateur.
